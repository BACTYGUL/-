Саламатсызбы! Менин атым Бактыгул 👋

Менин атым Бактыгул. Мен китеп окуганды жакшы көрөм жана өз ойлорумду, билимдеримди жазма түрүндө чагылдырганды жактырам. Веб-иштеп чыгуу аркылуу кооз, колдонууга ыңгайлуу жана эстетикалык долбоорлорду түзөм.

Учурда АЙТТИ окуу жайында IT тармагында билим алып жатамын. HTML, CSS, JavaScript жана React менен иштейм, Figma аркылуу UI дизайн жасайм.
